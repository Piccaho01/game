# M6 game shell: image prompts (paste into ChatGPT)

One image this milestone: the title screen's PATCH. **Attach** the listed images first, then send
the result back in the chat (or save it at the **Save as** path). No text, logos or Poké Balls.

The stone's panel is left blank on purpose: the game carves **PROJECT PATCH** into it itself, so
the letters stay crisp (ChatGPT garbles pixel lettering) and the name can change later.
