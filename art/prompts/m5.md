# M5 playtest build: image prompts (paste into ChatGPT)

Only two images this milestone. **Attach** the listed images first. Send the results back in the chat in this order (or save them at the **Save as** path). No text, logos or Poké Balls in any image.

The game runs fine without them: the officer is a grey stand-in and the broken bridge is made by a script from the bridge you already drew.
