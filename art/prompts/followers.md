# Walking sprites (followers): every stage of every line

The Patchling that walks behind the leader in the overworld (and the ones that roam the sanctuary) needs these. One image per line, **every stage**, in the same layout as the starters' old sheet. Owner's rule (2026-10-29): every new line comes with its walking sheet from now on.

**Attach** the listed images (the first is always the old sheet, for the size and style), run them in order, send the results back in the chat. No text, logos or Poké Balls.
