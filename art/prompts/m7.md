16 images. The four starter lines already have concept sheets, so their 8 forms only need one sprite prompt each. The asteroid and jet forms get concept art first. Every sprite prompt makes the front (left) and back (right) together in one image, so the back matches the front. **Attach** the listed images first. Send the results back in the chat in this order (or save them at the **Save as** path). No text, logos or Poké Balls in any image.

Go in order: each prompt attaches the image made just before it.
